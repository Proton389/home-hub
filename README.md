# Домашний хаб — версия для GitHub Pages

Сайт — один файл `index.html`, его бесплатно раздаёт GitHub Pages. Данные хранятся прямо в Google-таблице: игры — на Лист1, предзаказы — на Лист3, игроки — на Лист5, журнал партий и оценки — на листах «Журнал» и «Оценки», а записывает их небольшой скрипт `apps-script.gs`, который живёт внутри самой таблицы. Компьютер дома для работы не нужен.

- Смотреть сайт может любой, кто знает его адрес.
- Менять данные можно только с паролем. Устройство запоминает пароль после первого ввода.

## Шаг 1. Подключить Google-таблицу (≈5 минут)

Нужны права редактора таблицы. Если таблица чужая — сначала «Файл → Создать копию» и работайте с копией (тогда в `apps-script.gs` поправьте id листов в строке `SHEETS` — это числа после `gid=` в адресе каждого листа).

1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите всё в редакторе, вставьте содержимое файла `apps-script.gs`, нажмите 💾 «Сохранить».
3. Слева ⚙ **Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство**: название `PASSWORD`, значение — придуманный пароль. **Сохранить**.
4. Справа сверху **Начать развертывание → Новое развертывание**. Шестерёнка «Выберите тип» → **Веб-приложение**.
   - Запуск от имени: **От моего имени**
   - У кого есть доступ: **Все**
   - **Начать развертывание**.
5. Google попросит разрешение: **Предоставить доступ** → выберите аккаунт → **Дополнительные настройки** → **Перейти на страницу проекта (небезопасно)** → **Разрешить**. Предупреждение стандартное — это ваш собственный скрипт.
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. В `index.html` найдите строку `const API = '';` и вставьте адрес между кавычками:
   `const API = 'https://script.google.com/macros/s/…/exec';`

Проверка: откройте этот адрес в браузере — должен показаться текст с данными таблицы.

## Шаг 2. Выложить на GitHub Pages

1. На github.com: **New repository** → имя, например `home-hub` → **Public** (на бесплатном аккаунте Pages работает только для публичных) → **Create repository**.
2. **uploading an existing file** → перетащите файлы этой папки → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/home-hub/`.

## Как устроена таблица

| Лист | Что на нём | Как сайт его меняет |
|---|---|---|
| Лист1 | игры: `Coop`/`Noncoop`/`Traitor` (1 или 0), «Партий», «Где искать», «Правила», «Обложка», «Описание» и т. п. | только столбец «Партий» — скрипт пересчитывает его из журнала |
| Лист3 | предзаказы | целиком |
| Лист5 | игроки: «Игрок», «Партий», «Побед» | целиком; «Партий» и «Побед» скрипт пересчитывает из журнала |
| Журнал | одна строка — одна партия: ID, дата, игра, игроки, победители, заметка | добавляет и удаляет строки |
| Оценки | игра, игрок, оценка от 1 до 5 | одна строка на пару «игра — игрок» |

- Листы «Журнал» и «Оценки» скрипт создаёт сам при первой записи. Не переименовывайте их.
- **Вся статистика считается из журнала.** Числа «Партий» и «Побед» в таблице — просто копия для удобства: править их руками бесполезно, при следующей записи скрипт их пересчитает.
- Игрок, впервые появившийся в журнале, сам дописывается на Лист5.
- Количество игр каждого типа сайт считает по нулям и единицам на Лист1.

### Обновление скрипта

1. **Расширения → Apps Script** → удалите весь код, вставьте новый `apps-script.gs` (проще всего скопировать с https://raw.githubusercontent.com/Proton389/home-hub/main/apps-script.gs) → **Ctrl+S**.
2. **Развертывание → Управление развертываниями** → выберите активное развёртывание → **✏** → в поле «Версия» выберите **«Новая версия»** → **«Развернуть»**. Именно «Управление», а не «Новое развертывание» — иначе сменится адрес и его придётся заново вписывать в `index.html`.
3. Проверка: откройте адрес скрипта (`…/exec`) в браузере — в тексте должно быть слово `gameColumns`.

Пока новая версия не развёрнута, новые кнопки сайта сообщают: «Скрипт в таблице устарел».

## Журнал партий и оценки

- **Записать партию**: кнопка «+ партия» на карточке игры (или «+ Записать партию» в «Статистике») → отметьте, кто играл и кто победил → «Записать». Никого не отметили победителем — значит, победила игра (кооператив проиграли). Нового игрока можно добавить прямо в форме.
- **Ошиблись** — удалите запись в «Статистике → Журнал партий» и запишите заново. Счётчики пересчитаются.
- **Оценки**: откройте игру (клик по карточке) → у каждого игрока свои звёзды от 1 до 5. Повторный клик по той же звезде снимает оценку. На карточке видна средняя оценка; в подборе есть сортировки «Лучшие по оценке» и «Давно не играли»; в «Статистике» — «Лучшие по оценкам» и «Любимая игра» каждого игрока.
- **Поиск** в подборе ищет и по названию, и по столбцу «Где искать» — например, «шкаф F».

## Добавление и правка игр

- **Новая игра**: вкладка «Подбор» → **«+ Добавить игру»**. Поля формы — это заголовки листа с играми (кроме «Партий» — его считает журнал). Обязательно только «Название».
- **Изменить игру**: откройте игру (клик по карточке) → **«Изменить»**.
- Перед открытием формы сайт спрашивает и проверяет пароль. Записывается только то, что изменили: остальные ячейки строки и ручные правки в таблице не трогаются; новая игра дописывается в конец листа.
- **Переименование** заодно меняет название в журнале и оценках — партии и звёзды остаются при игре.
- Новый столбец на листе с играми сам появится в форме (и в окне «Подробнее»).

## Игроки, предзаказы, удаление игр

- **Переименовать игрока**: «Статистика» → таблица «Игроки» → карандаш рядом с именем. Партии, победы и оценки переходят на новое имя. Если такое имя уже есть — игроки объединятся (сайт переспросит).
- **Предзаказ пришёл**: «Предзаказы» → **«✓ Получен»** → откроется форма новой игры с названием из предзаказа → после сохранения игры предзаказ исчезнет. Если игра уже в коллекции, сайт просто предложит убрать предзаказ.
- **Удалить игру**: окно игры → «Изменить» → серая ссылка **«Удалить игру»** внизу формы. Записи в журнале остаются (это история), оценки игры удаляются.

## Резервные копии (раз в месяц)

Один раз: **Расширения → Apps Script** → вверху выберите функцию **setupMonthlyBackup** → **«Выполнить»** → Google попросит доступ к Диску — разрешите.
Сразу появится первая копия, а дальше скрипт сам делает копию всей таблицы **1-го числа каждого месяца** в папку **«Домашний хаб — резервные копии»** на вашем Google Диске. Хранятся 12 последних копий, более старые уходят в корзину Диска.
Восстановить: откройте нужную копию и скопируйте из неё листы (или работайте с копией как с основной таблицей).

## Приложение на телефоне

- **Android (Chrome)**: откройте сайт → меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
- **iPhone (Safari)**: откройте сайт → «Поделиться» → **«На экран „Домой“»**.

Сайт открывается мгновенно: сразу показывает данные с прошлого раза, а свежие из таблицы подгружает следом (обычно за 1–3 секунды) — так же и при обычном открытии в браузере.

Сайт откроется как отдельное приложение со своей иконкой. Без интернета (или когда таблица недоступна) он покажет данные, загруженные в последний раз, — сверху будет предупреждение, что изменения сейчас не сохранятся.

## Правила игр (PDF)

1. На Google Диске создайте папку, например «Правила», и загрузите туда PDF.
2. Нажмите на папку правой кнопкой → **Поделиться** → в «Общем доступе» выберите **Все, у кого есть ссылка** (роль «Читатель»). Файлы внутри получат тот же доступ.
3. В таблице на **Лист1** добавьте столбец с заголовком **Правила**.
4. Для каждой игры: правой кнопкой по PDF на Диске → **Поделиться → Копировать ссылку** → вставьте в столбец «Правила» напротив игры.

На карточке игры появится кнопка «Правила»: файл с Диска откроется прямо на сайте, любая другая ссылка — в новой вкладке. У игр без ссылки кнопки нет. Другое название столбца — поменяйте `rules: 'Правила'` в начале скрипта в `index.html`.

## Обложки игр

1. В таблице на **Лист1** добавьте столбец с заголовком **Обложка**.
2. Вставьте напротив игры ссылку на картинку — подходит любой из вариантов:
   - **Google Диск**: загрузите картинку (JPG/PNG) в папку с общим доступом «Все, у кого есть ссылка» → правой кнопкой → **Поделиться → Копировать ссылку**;
   - **картинка с сайта** (например, со страницы игры на Tesera): правой кнопкой по обложке → **Копировать адрес изображения** (ссылка должна вести на саму картинку, а не на страницу).

Маленькая обложка появится на карточке рядом с названием, большая — в окне «Подробнее». Если ссылка не открывается, картинка просто не показывается.

## Что важно знать

- **Сайт перезаписывает Лист3 и Лист5 целиком** (кроме строки заголовков). Столбцы без заголовка правее таблицы он не трогает. Если на этих листах есть формулы, сайт откажется сохранять и покажет ошибку. Случайную потерю можно откатить: «Файл → История версий».
- **На Лист1 сайт меняет только столбец «Партий»** — остальное там можно спокойно править руками, даже когда сайт открыт на телефоне. Правки из таблицы видны на сайте после кнопки «Обновить данные из таблицы» или обновления страницы.
- **Обнулить статистику**: в Apps Script выберите функцию **resetStats** → «Выполнить». Журнал очистится, счётчики станут 0; оценки останутся. Откат — «Файл → История версий».
- **Окно «Подробнее»** (клик по карточке игры) показывает все столбцы Лист1, которых нет на карточке. Добавьте, например, столбцы «Описание» и «ID на складе» — они появятся в окне сами, под своими заголовками.
- Листы можно переименовывать — скрипт ищет их по id. Столбцы тоже можно переименовать: тогда поменяйте их названия в начале скрипта в `index.html` (строки `COL`, `PLAYS`, `PRE`, `PL`).
- Сохранение занимает 1–3 секунды — так работает Google.
- Поменяли `apps-script.gs`? **Развертывание → Управление развертываниями → ✏ → Версия: Новая версия → Развернуть**. Адрес останется прежним.
- Сменить пароль — поменяйте свойство `PASSWORD`. Устройства спросят новый при следующем сохранении.

## Проверка скрипта без Google

`node test_apps_script.mjs` — прогоняет `apps-script.gs` на поддельной таблице.
